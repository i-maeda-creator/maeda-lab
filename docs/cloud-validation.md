# クラウド教科書 初版の検証（2026-09-19）

## 構造・生成
- `node tools/check-cloud.mjs`: 16トピック、8レベル、18ページ、内部リンク545件、5社のシナリオを検証。
- トピックIDの重複、前提が学習順の前にあること、関連先、HTML内ID、リンク先・アンカー、出典URL、シナリオの必須解説を確認。
- `git diff --check`、各JavaScriptの構文検査を実施。
- 表示は静的HTML。検索・既読・ゲーム以外の本文はJavaScript実行に依存しない。

## 実ブラウザ
- 目次と本文をデスクトップ幅および390pxのビューポートで視覚確認。ページ全体の横はみ出しなし。比較表は領域内を横スクロールできる。
- 全角「Ｓ３」が保存方式の1件に一致。レベル0との組み合わせで0件、解除で16件へ戻る。
- 読了ボタンで記録し、再読み込み後も保持。取消も確認。
- 大会管理で3段階を完走。設計を選び直した場合、最終ノートに新しい選択だけが残る。
- SNS、動画、練習記録、分析の各社でも3段階を完走し、解説と最終ノートを確認。
- ゲーム終了後に会社選択へ戻れる。前段階の設計を次の条件に表示。
- 確認中のブラウザconsole errorなし。

## 初版の範囲
- 概念を横断する基礎編。個別問題は未受領。今後、実際の問題から学びを抽出して既存本文を深める。
- ゲームは定性的な選択教材。実システムの性能や課金を計算しない。ゲーム進行は永続保存しない。
- 既読情報は端末内保存で、アカウント間同期は行わない。保存が利用できない場合は画面で説明する。
