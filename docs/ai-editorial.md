# AIの選定・解説・履歴を更新する

- 編集元は `content/ai/catalog.json`。`node tools/build-ai.mjs` でホームの指定ブロックと `ai/index.html` を生成し、両方をコミットする。
- ホームの選定は `editions` の最後の `featured`。入れ替える場合は既存editionを変更せず、新しいID・日付・理由・掲載ID一覧を末尾に追加する。
- 新しいAIは一度だけ `tools` に追加。ホームから外しても削除しない。名称変更は同じIDで管理し、旧称を解説に残す。
- 各editionの `names` に当時の表示名を保存する。後の改名で古い一覧の名称を書き換えない。
- 短い用途説明、公式URL、確認日、必要な注記を更新する。過去の掲載から復元しただけの項目は `verified: null` とし、最新仕様を確認済みと扱わない。
- 公式発表の年月日と、このサイトの掲載日は別物。初回掲載日が不明なら推定しない。baselineはGit ea53536の既存38件を2026-09-20に復元した記録。
- `timeline` は公式発表の事実（fact）、編集者の分析（analysis）、根拠URLを分ける。発表・話題化・継続利用の定着を同一視せず、人気度を数値化するなら比較可能な根拠を別途用意する。
- 現在の図は役割の広がりを示す。市場シェア、流行の大きさ、旧技術の終了を表さない。
- 変更後は `node tools/check-ai.mjs`、ブラウザで検索・掲載状態・用途フィルター、履歴リンク、PCとモバイルを確認する。
- 更新は依頼時に調査して行う。自動巡回・自動更新は現在設定していない。
