# Accounting の編集

## 読者と構成
- 大学生・社会人向け。用語を知っている前提にしない。1ページ1テーマを保ちつつ、考え方・図・計算例・間違えやすい点まで説明する。漫画は必須にせず、難しい区別を伝える場面で使う。吹き出しは125文字以内を目安とする。
- 架空の会社の幹部・星野と、同社に勤めながら会計を学ぶ堀内が主人公。堀内を資格取得済みと描かない。役職や年齢の追加設定は必要に応じて行う。
- 漫画の番号順は左上→右上→左下→右下。スマートフォンでは縦一列。同じ順序をDOMでも保持する。
- 図と説明が主役。漫画は必要な場面だけに登場する。銀行・店頭・倉庫など、内容に合った背景、画角、手の動き、手元の資料を使う。用語・資料は開閉式。本文と台詞はHTMLで、拡大や読み上げに対応。
- サイトには資格名や試験対策の看板を置かない。科目の目次だけを設ける。まだ網羅していない科目を完成済みと表現しない。

## 科目と英語の確認（2026-09-21）
- 公式Q&A: https://www.fsa.go.jp/cpaaob/kouninkaikeishi-shiken/qanda/
- 短答は財務会計論・管理会計論・監査論・企業法。論文は会計学（教材上は財務・管理に整理）、監査論、租税法、企業法、選択科目（経営学・経済学・民法・統計学から1科目）。サイトでは試験形式別に重複させず、全9分野を学習用に並べる。
- 冒頭に「まずは簿記」「会計の英単語」を置く。
- 令和9年から英語が入るのは短答の財務・管理・監査の一部。全部英語ではない。2026年5月25日の公表による初年度の配点は総点の5〜6％程度。古い方向性の「1割程度」と混同しない。
- https://www.fsa.go.jp/cpaaob/kouninkaikeishi-shiken/r9shiken/r9eigosyutudai.html
- https://www.fsa.go.jp/cpaaob/kouninkaikeishi-shiken/r9shiken/R9eigosyutudai.pdf

## 図解の編集
- ユーザー指定の参考：大手町のランダムウォーカー氏の会計クイズ。公開例 https://note.com/ote_walk/n/n962843b5a75d を参照。図や人物を転載せず、同じ尺度で比較し内訳を色分けする考え方を採用する。
- 貸借対照表は左に資産、右に負債・純資産。資産は青、負債は橙、純資産は緑。文字ラベルも必ず付ける。左右の合計を検証する。
- 金額比を表す図は同じ尺度で描き、その旨と単位を明示する。概念図の箱を金額比と誤認させない。実企業の数字に見せず、架空の例と明記する。
- 仕訳は左右、入金と収益は時間軸、固定費・変動費は積み上げ棒、平均とばらつきは共通尺度の棒グラフで示す。

## 2026-09-21 改訂：説明と章末問題
- ユーザーの指示により、全20話に説明・具体例・誤解の指摘を追加し、漫画は8話のみ表示。従来のURLは維持する。
- content/accounting/challenges.json に11科目分の章末問題を置く。資格名をページに出さず「発展問題」とする。公開問題の資料計算・事例論述形式を参考にしたオリジナル教材と明示し、実際の過去問や完全再現とは表現しない。
- 数値と前提を独立に設定し、資料→設問→任意のヒント→開閉式解答→途中式・判断の根拠の順とする。難しい問題の前に必要な知識と本文へのリンクを設ける。
- 形式参照：2026年の公開資料 https://www.fsa.go.jp/cpaaob/kouninkaikeishi-shiken/2026shiken.html 、論述資料 https://www.fsa.go.jp/cpaaob/kouninkaikeishi-shiken/r8shiken/ronbun_mondai_r08.html 。問題文・企業設定・数値は転載していない。
- 税務の難問は税率・損金算入・回収可能性を与件として明示。企業法は通常の取締役会・監査役設置会社に限定。民法は契約成立・解除・損害賠償を分ける。
- 計算問題は独立計算で答えと途中式を照合する。数値の桁、単位、端数処理、計算の前提を同時に確認する。
