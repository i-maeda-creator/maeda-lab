# クラウド教科書・統合記録

## 2026-09-19 初版
- 入力: 教科書の設計方針。個別の学習問題はまだ受領していない。
- 基本概念を初心者向けの8レベルに整理し、今後の問題を統合する土台を作る。
- 本文・関連リンク・公式資料を概念単位で管理し、検索と既読管理、設計判断のサクセスモードを補助として用意する。
- 新しい問題の受領時には「中心テーマ / 前提 / 周辺 / 比較 / 誤解 / 実務 / 統合先 / 章追加 / 本文改善 / 関連リンク」を記録する。
- 実装: 8レベル・16トピックを作成。既存のネットワーク深掘り教材へリンクし、図解・比較表・公式資料を付けた。
- 補助機能: 本文検索、レベル絞り込み、端末内の既読保存、5種類の会社×3段階のサクセスモード。
- 整理した誤解: DNSと本体通信の違い、LBと能力増強の違い、バックアップと複製の違い、認証と認可の違い。
- 検証内容は `docs/cloud-validation.md` に記録。
