CHAPTER END / 応用・総合 · 目安 15分

取引をつなぎ、期末残高を復元する

資料を読み、条件を整理し、根拠まで説明する。

公開問題の形式を参考にしたオリジナル教材です。過去問そのものではありません。

必要な知識資料設問解答・解説

解く前に、ここを確認。

  1. 利益は収益−費用。借入元本と返済は利益を動かさない。
  2. 売上を記録するとき、売れた商品の原価を費用に振り替える。未払いでも当期の給与は費用にする。

本文に戻る：まずは、五つの引き出し。 ／ 借方は左、貸方は右。 ／ 領収書を、仕訳に変える。

GIVEN DATA

資料と条件

  1. 単位は万円。期首は現金100、資本金100だけがある。税金は考慮しない。
  2. 銀行から60を借り入れ、商品40を掛けで仕入れた。
  3. 原価30の商品を90で掛け販売した。売上の計上条件を満たしている。
  4. 売掛金50を回収し、買掛金25を支払った。
  5. 当期の給与12と利息2を現金で支払った。別に、当期の未払給与3がある。ほかの取引はない。

設問

  1. 期末の現金・売掛金・商品・買掛金・借入金・未払給与を求める。
  2. 当期利益と期末純資産を求め、資産＝負債＋純資産が成立することを示す。
行き詰まったら、ヒントを開く

現金の増減、利益の計算、資産負債の残高を別々に集計し、最後に照合します。

解答と、考え方を開く

現金171、売掛金40、商品10。負債合計78、利益43、純資産143。

解く順番

  1. 現金＝100＋60＋50−25−12−2＝171。売掛金＝90−50＝40。商品＝40−30＝10。
  2. 買掛金＝40−25＝15、借入金＝60、未払給与＝3。負債合計は78。
  3. 給与費用は支払済み12＋未払3＝15。利益＝90−30−15−2＝43。
  4. 純資産＝資本金100＋利益43＝143。資産合計171＋40＋10＝221。78＋143＝221と一致する。
誤りやすい判断

仕入40をすべて費用にしないこと。売れていない商品10は資産として残ります。
